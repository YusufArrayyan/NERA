Klimesch, W.

"EEG alpha and theta oscillations reflect cognitive and memory performance: a review and analysis."

"EEG-neurofeedback for optimising performance. III: A review of sensory-motor rhythm and alpha-theta training."

Fondasi modul umpan balik interaktif NERA untuk menjaga stabilitas fokus optimal siswa.

Roy, R. N. et al.
