### Contributing to Documentation

```
If you find an error:
  1. Flag in team Slack
  2. Create issue in GitHub
  3. Submit PR with fix
  4. Get review from doc owner

If you want to add a section:
  1. Discuss with team lead
  2. Create new document or add to existing
  3. Follow format/style of existing docs
  4. Get review before merge
  5. Announce update in team meeting

If creating new doc:
  1. Check if it already exists
  2. Name clearly (verb-adjective-noun format)
  3. Add metadata (created date, owner, version)
  4. Add to this index
  5. Link to related docs
```
